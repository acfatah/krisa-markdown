## Menjana semula

```bash
bun run fetch           # bab + templat
bun run fetch:pdf       # sertakan PDF rasmi
bun run fetch:refresh   # abaikan cache
```

Memerlukan Bun sahaja; tiada kebergantungan masa larian luar.
Muat turun disimpan dalam `.cache/`.
