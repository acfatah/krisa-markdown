# 5.4 Faktor Kejayaan

Untuk memastikan aktiviti berjaya dilaksanakan, berikut adalah faktor kejayaan
utama yang perlu dipertimbangkan sebelum dan semasa aktiviti dilaksanakan:

1. Spesifikasi Reka bentuk Sistem (SDS) yang didokumenkan adalah lengkap dan
   memenuhi kehendak pengguna.
2. Pasukan pengaturcara program berupaya menterjemahkan SDS kepada kod aturcara
   dan logik pemprograman, mempunyai kemahiran dan kepakaran dalam bahasa
   pengaturcaraan yang dipilih dan SQL (*skill coding dan SQL query*).
3. Bilangan pengaturcara yang mencukupi dan bersesuaian dengan masa pembangunan.
4. Kelengkapan tools dan persekitaran pembangunan yang sempurna.
